Detailed Description

The FetchData class exists to fetch relevant data, and save it in a local .json database.

It is used only via the constructor, since the only data stored in a FetchData object itself is the selected language. It's aim twofold:

  1. To create the .json files, that are then read in other places in the code.
  2. To handle any errors that may arrise from a mismatch of data between different APIs, or network issues

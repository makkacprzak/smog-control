◆ getDataPoints()

QVector< QPointF > Jfile::getDataPoints ( const std::string & station,
const std::string & param ) const

Get data displayable on QChartView for specific station-param pair.

First separates only relevant parts of file_ attribute
Then parses this data into data a format that is easily interpreted by the QChartView UI element

Parameters
stationExact name of station requested by user, or string that represents the average of all measurments in city
paramExact name of air parameter requested by user
Returns
A QVector of QPointFs, which are {date in qint64 ms since epoch format, value in double format} pairs sorted in ascending order
